## 2. Safety invariants (non-negotiable)

1. **Nothing reaches the cable without the gate.** `--commit` runs
   `gate_for_write` first. Dry-run is the default.
2. **A write is never retried.** The firmware validates CRC and rejects
   silently; resending races the device.
3. **An abort never sends the commit.** Flash keeps the previous preset.
4. **Flash writes are spaced (2 s), counted, and warned about (≥50/day).**
5. **A journal failure never re-sends anything.** The write already happened;
   report it as a warning (`The write happened, but the journal could not be
   saved.`), never as a reason to write again.
6. **Every edit disarms a pending write.** Cursor motion does not.

The limits are the *observed envelope of the 11 official presets*, not a proof
of hardware safety. Say so in the UI.

### M5.1 — flash policy (`new crate: crates/auri-policy`)

State, mirroring `FlashState`:

```rust
struct FlashState {
    day: Option<Day>,        // { date: "YYYY-MM-DD", count: u64 } — None = reset day
    total: u64,
    last_write_at: Option<i64>,  // epoch ms; None = UNKNOWN, never "no cooldown"
    session: u64,
}
```

Constants: `MIN_INTERVAL_MS = 2000`, `DAILY_NOTICE_THRESHOLD = 50`.

Required behaviour (all pure, clock injected — never call `now()` inside):

| fn | behaviour |
|---|---|
| `local_date_key(now)` | **local** calendar date, not UTC. `YYYY-MM-DD`, validated (leap years). |
| `can_write_now(state, now)` | `{ok, wait_ms}`. Unknown `last_write_at` ⇒ full 2000 ms wait. Negative elapsed ⇒ full 2000 ms wait, never "wait until the old clock catches up". |
| `observe_flash_state(state, now)` | Rebase `last_write_at` forward when `now < last_write_at` (clock went backwards). |
| `record_write(state, now)` | `day.count+1` (reset if the date rolled), `total+1`, `session+1`, `last_write_at = now`. **Saturate, never cap.** |
| `daily_notice(state, now)` | date matches today **and** `day.count >= 50`. |

Storage: `~/.local/share/auri/flash.json` (XDG), created with `0600`.
A read error ⇒ treat as fresh state (conservative: unknown ⇒ full wait).

**Only `commit = true` calls `record_write`.** A RAM-only write does not touch
flash and must not count or start the cooldown.

> `WRITE_SPACING_MS` is already declared and re-exported in
> `crates/auri-transport/src/writer.rs` but **never called** — `pause()` is
> only used with `REPORT_GAP_MS` and `SETTLE_MS`. Either enforce the spacing
> there or (better) keep the decision in the caller, which owns the clock.

### M5.3 — checklist model (`crates/auri-policy/src/checklist.rs`)

**Lamps** `a b c d e f g k`:

```text
lamp_of(code): prefix "d7" or "k" → k;  prefix in {a,b,c,d,e,f,g} → that;  else f
state:  own blocking reasons          → Fail
        only waived reasons           → Waived   (YOLO only; class 1 never)
        metrics.sections present, or f → Ok
        otherwise                      → Unknown  (early f:codec refusal)
```

**Criterion display values** (from `criteria.ts` — read the *same* verdict,
never run a second gate; a missing metric renders `null`, never invented):

| id | value | limit |
|---|---|---|
| a | `max over sections/words of (\|word\| / COEFFICIENT_ABS_WORDS[i]) * 100`, 1 decimal, `%` | `100 %` |
| b | `r {max pole_radius}`, 6 decimals | `POLE_RADIUS`, 6 decimals |
| c | `max section.full_peak.db`, 2 decimals `dB` | `SECTION_PEAK_DB`, 1 decimal `dB` |
| d | `metrics.internal_audible.db` | `INTERNAL_AUDIBLE_DB` |
| e | `metrics.output_audible.db` | `OUTPUT_AUDIBLE_DB` |
| f | `CRC {payload_crc}` | — |
| g | `metrics.preamp_db`, 1 decimal `dB` | `-25.5 … -0.5 dB` |
| k | *(no single number)* | — |

**Items** (all `required` unless noted; `can_write = every required item satisfied`):

| id | required when | satisfied when |
|---|---|---|
| `gate` | always | `verdict.ok` |
| `volume` | always | user confirmed the volume is down |
| `connection` | always | user confirmed they will not disconnect |
| `experimental` | curve has HS/LP/HP **or** any band above 20 kHz | user confirmed |
| `spacing` | always | `can_write_now(...).ok` |
| `yolo-session` | profile == yolo | session phrase confirmed |
| `yolo-write` | profile == yolo | per-write confirmation (every write) |

**Loudness** (`src/policy/loudness.mjs`):

```text
LOUDNESS_JUMP_DB        = 3
LOUDNESS_TOLERANCE_DB   = 1e-4      (Q23 rounding bound ≈ 1.95e-5 dB)

delta = new_level_db - last_written_level_db
jump         := delta is finite && delta >= 3 - 1e-4
unknown_state:= levels non-finite, or session_write_count <= 0,
                or last journal status == "interrupted"
warn         := jump || unknown_state          (order: jump, then unknown-state)
```

`last_written_level_db` = the newest journal entry with `status == "ok"`
(the newest entry of *any* status is used only to detect `interrupted`).

### M5.4 — journal (`crates/auri-policy/src/journal.rs`)

Append-only JSONL at `~/.local/share/auri/journal.jsonl`.

```rust
struct JournalEntry {
    ts: i64,                 // epoch ms
    status: Status,          // Ok | Interrupted | Simulated
    crc: String,             // "0x4fff"
    bands: Vec<Band>,        // snapshot — needed to recompute level_db later
    preamp_db: f64,
    profile: Profile,
    label: String,           // sink label
}
```

Rules:
- Append **after** the write settles. If the write failed mid-way, append
  `Interrupted` (that is what makes the next session's state "unknown").
- Journal failure ⇒ warn and continue. **Never re-send.**
- `last_written_level_db()` scans backwards for `status == Ok`.
- The cable never reports what it stores — the journal is the only memory.
  Say so in the UI.

### M5.5 — UI

**CLI (`main.rs::send`)** — after a successful `--commit`:
- print the counters (`this session` / `today` / `in total`)
- print `2 s spacing between writes respected` or the remaining wait
- print `Predicted level 300 Hz–3 kHz`, `Last written curve`, `Jump`
- warn when `loudness.warn`
- print the daily notice at ≥50 writes

**TUI (`tui/ui.rs` + `tui/app.rs`)** — shipped **minimal** (user decision:
no bloat, more minimal than open-auri): no VU meter, no lamp grid, no
criteria table. The gate block gained four compact lines instead:

- Level line: `level 300 Hz–3 kHz · last written · jump` — computed data.
- Warning sentence (re-authored) when `loudness.warn` (+3 dB jump or
  unknown state).
- Confirmations on one line: `[x] volume lowered  [x] keep connected`
  (+ experimental when required, + the two YOLO items under Yolo) — all must
  be ticked before Write enables. Show `Complete every item to enable
  writing.` while locked.
- Counters line: `this session / today / in total`, 2 s spacing status and
  `to {target}` (dry-run or the sink label).
- Flash notice once the daily threshold is hit.
- Arm state: `ARMED`, then success `written to the cable. CRC {crc}.`
- Focus: `Tab` moves between the band table and the checklist (border turns
  cyan — never yellow, that belongs to the table cursor), `Space` toggles the
  focused confirmation, `j`/`k` walk the confirmations while focused.

Keyboard: keep it vim. `w` stays the write gesture (arms only when the
checklist allows, else the lock message).

## 5b. Done — the official presets

The 11 curves Kuba ships (plus Neutro) are built in, minimal by design:

- `crates/auri-cli/src/presets.rs` is **generated** by `tools/gen-presets.mjs`
  from the reference catalog. Only ids, labels, preamp, CRC and the band
  numbers are copied — the reference's pt-BR prose is AGPL and stays out.
- `auri presets` lists them (`id`, `label`, preamp, official CRC).
- `auri write --preset <id>` and `auri tui --preset <id>` load one; the file
  argument and `--preset` conflict. `tui --preset` starts the editor on that
  curve (still dry-run unless `--commit`).
- Tests pin every curve: it must encode to its **official CRC** and pass the
  standard gate, so a regeneration that drifts is a red test. `neutro` must
  equal `CurveFile::neutral()`.

Searched prior art while planning: the official page is WebHID
(`equalizador.kuba.audio`), Danger Circuits shipped an Android WebView bridge
(no source), and the wider ecosystem (AutoEq, EasyEffects, Equalizer APO) has
import/export formats. None of that is needed for a preset list; open-auri's
`io/equalizer-apo.mjs` is the natural next step **if** export is ever wanted.

## 7. Backlog / known gaps

- **`just` not installed locally** — recipes exist, run `cargo` directly.
- **Alternative to hidapi** — `hidapi` links GPL-3.0-or-later, which makes a
  *distributed* binary a GPL work. The `HidSink` trait already abstracts it;
  a permissive backend (e.g. `rusb`/`nusb`) is a drop-in for releases.
  Decide before shipping binaries.
- **Cable not plugged into this machine** — `auri devices` reports
  `no cable found (13058:8902)`. Real-hardware tests need the device.
- **`App::neutral()` is `#[cfg(test)]`** — the binary always starts from a
  `CurveFile`.
- **Grid cache** — `CascadeScan` rebuilds the log grid every call (~0.8 ms).
  Fine as-is; only cache it if a profile shows up in a trace.
- **Open questions from upstream** (`open-auri/docs/open-questions.md`):
  flash endurance is ❌ untested (the whole reason for M5's counters),
  meaning of the other tags, and behaviours B3/B5/B6/B8/B9/B11.

## 8. Conventions

- **Commits:** Conventional Commits, one milestone per commit, subject ≤ 50.
- **Clippy:** `cargo clippy --workspace --all-targets -- -D warnings` must be
  clean. `unwrap_used` is a workspace lint; `allow-unwrap-in-tests = true`.
- **NaN:** every limit comparison is `!(x <= limit)` so NaN fails. There is a
  crate-level `#![allow(clippy::neg_cmp_op_on_partial_ord)]` in
  `auri-gate/src/lib.rs` with the reason — keep it.
- **Formatting:** `.rustfmt.toml` uses nightly-only options; stable `cargo fmt`
  warns and skips them. Not a failure.
- **Oracles:** never vendored, never copied. Read at test time, skip when
  absent.
- **No retry, ever.** Not in the transport, not in the CLI, not in the TUI.
