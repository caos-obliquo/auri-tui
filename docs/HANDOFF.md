## What this is

`auri` — offline terminal control for the **Kuba Auri (CB5100)** DSP cable.
Rust workspace, MIT. The cable stores one EQ curve in flash; the tool reads
nothing from it and writes only curves the safety gate approves.

## Layout

| Crate | Role | Key files |
| --- | --- | --- |
| `auri-codec` | byte-exact `0xCB` wire codec, no USB | `band.rs`, `design.rs`, `quantize.rs`, `encode.rs`, `crc.rs`, `magnitude.rs` |
| `auri-gate` | verdict before any write; 19 reason codes | `gate.rs`, `thresholds.rs` (generated), `policy.rs`, `level.rs` |
| `auri-policy` | flash spacing/counters, loudness warning, JSONL journal, checklist | `flash.rs`, `journal.rs`, `checklist.rs`, `loudness.rs`, `store.rs` |
| `auri-transport` | HID writer; abort never commits | `writer.rs`, `real.rs`, `fake.rs` |
| `auri-cli` | the `auri` binary + TUI | `main.rs`, `curve.rs`, `presets.rs` (generated), `tui/{app,mod,ui,plot}.rs` |

Data flow: `CurveFile` → `encode_reports` → 9×31-byte reports + commit report.
`gate_for_write` judges the curve first; the TUI re-judges on every keystroke.

## Safety invariants — do not break

1. Nothing reaches the cable without the gate; `send()` re-checks it.
2. A write is **never retried**.
3. An abort **never sends the commit** — `write_curve` stops before it.
4. Arm handshake: `w` twice; any curve edit disarms, cursor motion does not.
5. 2 s spacing + counters; only `commit=true` records a write (dry-run is RAM
   only, no counters, no cooldown).
6. Journal failure never re-sends; `committed_write` has exactly one
   `write_curve` call.
7. Dry-run is the default everywhere; `--commit` is explicit.
8. TUI startup opens no HID and writes no state files (test:
   `opening_the_editor_creates_no_state_files`).

## Reference projects (what to borrow, what not to)

- **open-auri** (`github.com/marco-jardim/open-auri`, AGPL-3.0): behavior
  reference for protocol, gate thresholds, presets, `level_db`. Never copy
  code or prose; reimplement and cite in `THIRD_PARTY_NOTICES.md`.
- **eqtui** (`github.com/SiputBiru/eqtui`, GPL-2.0): closest Rust + Ratatui EQ
  TUI. Worth borrowing: `{`/`}` profile cycling (our deferred preset
  cycling), a read-only `[RO]` marker for built-in presets, right-panel
  response graph. Not applicable: PipeWire daemon/TUI split (the cable keeps
  its own state), Normal/Insert/Visual/Command modes (we stay single-mode and
  minimal).
- **tui-equalizer** (`ratatui/tui-widgets`): band-bar widget; not adopted — we
  draw a braille magnitude curve (`tui/plot.rs`).
- **AutoEq**: biquad math source (MIT).
