## 1. Scope

This review covers the work after `1907b73` (HANDOFF doc) up to the branch

with `{`/`}`, a new `export` command, docs, and the git reconciliation with
`origin/main`.

## 2. What changed, phase by phase

**A — panic hardening.** `out()`/`err()` in `main.rs` buffer into a `Vec` and
`write_all`, so a closed stdout (`auri presets | head -1`) exits 0 instead of
panicking with *Broken pipe*. In `tui/app.rs`, `band()`/`band_mut()` and
`clamp_row()` replaced direct `self.bands[self.row]` indexing; every row is
clamped at construction and on every mutation. In `auri-gate`, every `expect`
on a documented invariant became a total fallback (`unwrap_or`, `as u32` with
domain comments, `let-else`) — no numeric change on any path the parity corpus
covers. `expect_used` was dropped from the workspace lints because this clippy
version does not honour `allow-expect-in-tests`.

**B — regression pins.** `crates/auri-cli/tests/cli.rs` (closed stdout,
`show --preset` pass/fail) and two app key-spam tests (empty band list,
single-band clamp). The gate parity corpus (336 verdicts, 14 `level_db` cases)
and the codec byte-exact tests were re-run untouched and stayed green.

**C — TUI preset cycling + `[RO]`.** `presets::index_of()` (added to the
generator template *and* the generated file, so regeneration keeps it).
`App::preset_index` tracks the loaded preset; `{`/`}` wrap through all 12
presets; `load_preset()` updates `bands`, `preamp_db` and `original`, and runs
through `edited()` so the arm is always cleared. Any edit clears the marker;
`r` restores the *loaded preset* (not the session's first curve), so `[RO]`
and `r` can never disagree. Header shows `preset <label> [RO]` — cosmetic
only, never gates a write. `decode()` needed no change: `{`/`}` arrive as
`Key::Char`.

**D — `auri export`.** New `crates/auri-cli/src/export.rs`: `ExportFormat`
(`clap::ValueEnum`) + `render()`. APO emits `Preamp` and all ten `Filter N:`
lines (`OFF` bands included, so numbering matches the cable); PipeWire emits
`band.N.type/frequency/gain/q/enabled` key=value lines. Offline, no HID, no
state files; reuses `curve_arg()` and the fallible `out()`. Three unit tests
+ two integration tests.

**E — docs.** HANDOFF status + next steps, TODO §5b, CHANGELOG `[Unreleased]`
(Added/Fixed), README (export row, usage, key table).

**F — git reconciliation.** `origin/main` had the squashed `10559ae`; local
`main` had the split history plus presets (ahead 3 / behind 1). Trees differed
only by the four preset files, so the merge was trivially safe: `a098a9b`
(merge into `main`, tree byte-identical to pre-merge), pushed
(`10559ae..a098a9b`). `main` merged into `chore/m6-packaging` (`bfd32e0`) and
the branch pushed. No force-push was used — no history was lost anywhere.

## 3. Safety invariants — re-checked

1. Nothing reaches the cable without the gate — `load_preset()` goes through
   `edited()` → `recompute()` → `gate_for_write`; cycle keys are exact
   `Char('{')`/`Char('}')`, no bypass.
2. Write never retried — untouched.
3. Abort never sends commit — untouched.
4. Arm needs `w` twice; any curve edit disarms — preset load is an edit, the
   arm is cleared before the new curve can be written.
5. 2 s spacing + counters — untouched.
6. Journal failure never re-sends — untouched.
7. Dry-run default — untouched; `export` is offline by construction.
8. TUI startup opens no HID and writes no state files — untouched; cycling
   only replaces in-memory curve data.

## 5. Risks and known gaps

- Gate total-path fallbacks (`unwrap_or`, `as u32`) are unreachable on any
  input the corpus covers; a future caller breaking the documented domain
  (e.g. `stage` outside `1..=10`) would get a verdict instead of a crash —
  conservative, but silently.
- `{`/`}` cycling and export are only exercised by unit/integration tests;
  the TUI paths were not manually key-driven in this session beyond decoding.
- `App::neutral()` is still `#[cfg(test)]` (TODO §7, known).
- The `CascadeScan` grid rebuild (~0.8 ms) is still uncached (deliberate).
- Hardware validation and the fully-static musl build remain open (cable
  absent here; static eudev blocker), unchanged from HANDOFF.
